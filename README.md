# Aeon 在庫管理アプリ

HTML/CSS/JavaScriptだけで動く、ローカル用の在庫管理アプリです。
Node.js、npm、データベース、外部サービスは使いません。

## 使い方

1. このフォルダをPCに保存します。
2. `index.html` をブラウザで開きます。
3. 商品登録、入庫、出庫、在庫確認を行います。

## 機能

- 商品登録
  - 品番
  - 品名
  - サイズ
  - 色
  - 数量
  - カートン入数
- 入庫、出庫
  - 在庫一覧の各商品行で数量を入力
  - 在庫一覧の各商品行でカートン数を入力
  - 一覧上部の入庫ボタン、出庫ボタンで一括反映
  - 入力中の数字はソートや検索をしても保持
  - カートン数は `カートン数 × カートン入数` で数量換算
- 在庫一覧
  - 初期表示は `品番 > 色 > 品名` 順
  - 各列でソート可能
  - 商品の編集、削除
- 入出庫履歴
- JSON出力、JSON読込
- 全データ削除

## データ保存について

在庫データはブラウザの `localStorage` に保存されます。

そのため、次の場合は同じデータを自動では共有できません。

- 別PCで開く
- 別ブラウザで開く
- ブラウザの保存データを削除する

PC間やブラウザ間でデータを移動する場合は、アプリ内の `JSON出力` と `JSON読込` を使ってください。

## GitHubから会社PCへ取得する場合

Gitが使えるPCでは、次のコマンドで取得できます。

```powershell
git clone https://github.com/fgsawa-spec/aeon.git
```

Gitが使えないPCでは、GitHubの画面からZIPでダウンロードして展開してください。

取得後、フォルダ内の `index.html` を開くとアプリを使えます。

## 注意事項

- このアプリは1人で使うローカル管理向けです。
- 複数人同時編集や自動同期には対応していません。
- 重要な在庫データは定期的に `JSON出力` でバックアップしてください。
